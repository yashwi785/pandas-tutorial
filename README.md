Beginner-friendly notebooks and Python scripts covering core **Pandas** workflows for data analysis, cleaning, and preprocessing. Built alongside my **[NumPy-tutorial](https://github.com/yashwi785/NumPy-tutorial)** repository as part of my AI & Data Science learning track.

---

## 📂 Topics Covered

| Module | Concepts & Methods |
| :--- | :--- |
| **1. Series & DataFrames** | Creating Series and DataFrames, inspecting structure (`.head()`, `.tail()`, `.info()`, `.describe()`, `.shape`), and checking dtypes |
| **2. Selection & Indexing** | Label-based selection (`.loc`), integer-position indexing (`.iloc`), column slicing, and boolean conditional filtering |
| **3. Data Cleaning** | Detecting and handling missing values (`isna()`, `fillna()`, `dropna()`), removing duplicates (`drop_duplicates()`), and renaming/dropping columns |
| **4. Grouping & Aggregation** | Splitting data with `groupby()`, multi-metric summaries with `.agg()`, `value_counts()`, and sorting (`sort_values()`) |
| **5. Date & Time Handling** | Parsing timestamps via `pd.to_datetime()`, extracting year/month/day/weekday using `.dt`, date-range filtering, and time-series resampling |
| **6. Merging & I/O** | Reading/writing CSV and Excel files (`read_csv()`, `to_csv()`), concatenating (`pd.concat()`), and joining DataFrames (`pd.merge()`) |
